Chord stamp

Click a column on a staff, then click a shape. It lands there and the cursor steps right, so you can stamp again.

Keys
  • Click + typePut a fret or symbol in that cell. Nothing else moves.
  • EnterNext string down, same column (Shift = up). For stacking chords.
  • TabJump to the next note column, leaving one dash.
  • SpaceBlank the cell and step right.
  • Shift+arrows / dragSelect a region. Ctrl+C / X / V work on it.
  • Ctrl+DRepeat the selection to the right.
  • Ctrl+SpaceInsert a column (also Insert key).
  • Ctrl+BackspaceRemove a column (Ctrl+Delete removes forward).
  • …with ShiftInsert / remove on the current string only.
  • Ctrl+BBar line down all strings.
  • Ctrl+EnterNew staff below.
  • EndJump past the last note on the string.
  • Ctrl+PPlay / stop. Plays the selection if there is one.
